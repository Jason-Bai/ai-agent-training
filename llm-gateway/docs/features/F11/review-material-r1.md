## 三维重点

1. 需求：所有名额均为请求级；内部恢复不再次申请；身份来自鉴权；Provider组未重引入。
2. 一致性：拒绝零上游/Attempt/预留；pending拒绝不污染；全局/Agent原子检查；凭证幂等/归属；日志与错误类别安全。
3. 系统：普通/探测/流式共享一个实例；Task建造失败、首次字节码前取消、ACK不确定、取消与清理超时及迟到Task退出；全部旧功能及费用/终态语义；真实失败是否可能由本次代码造成，不能因旁路503就停止沿调用链审查。

审查者只读，禁止测试/付费调用/修改；通用工具并未强制只读，这只是任务约束。需要最小实验由主执行者运行并回传原始输出。问题按实际P0—P3分级，不凑数量；无代码阻断项也须独立说明关键验收证据缺口与未验证边界。
