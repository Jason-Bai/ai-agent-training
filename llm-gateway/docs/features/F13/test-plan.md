## 1. 范围与通过标准

基线为F12完整2508节点（含42个live），见[F12最终证据](../F12/test-plan.md#7-修复后完整版本回归第2轮复核)。开始实现前重新收集安全基线和实际节点；历史通过不代替本轮回归。阶段A交付三模型接入/计量，阶段B交付自动路由；记录各阶段结果，最终全量和完整独审覆盖整个F13。

### 1.1 三类验收分别判断

| 验收对象 | 通过条件 | 证据范围 |
| --- | --- | --- |

| 系统正确性 | 硬约束、权限、零调用拒绝、期限、次数、终态、seq、计费及资源断言全部通过；注入不能选白名单外组或改变执行权限；相关回归及最终全量通过，独审无P0—P2 | Mock、屏障、HTTP/PG/OS及真实执行各自留证，不能用质量准确率豁免安全和账务错误 |

### 1.2 统一断言

每个HTTP错误检查四字段、success=false、具体code、data=null、请求ID及脱敏；成功体只含原text/usage/可选parsed。输入未经认可前不保存原body，Trace不包含正文、回答、密钥、凭据引用、地址或上游原文。已开始SSE的故障以原事件协议表达。

每条业务路径按request_id关联：实际Provider调用及出站参数、请求/Attempt、分类用途、选定组与端点、事件、费用预留/结算/待核实、余额和资源。不能只断言响应或返回文字；阶段A不适用的分类检查明确省略。禁止替换被测Router、计价器、生命周期或Schema校验为恒定成功。

## 3. 执行计划、证据与结论

### 3.1 环境和隔离

Python3.12、项目锁定依赖、独立临时PostgreSQL与Gateway进程、独立临时YAML/价格/凭据引用、空闲端口；不读维护者模型绑定决定测试预期。Mock走真实生产主链；协议替身仅替换上游HTTP，业务故障不靠新增产品开关。宿主数据库停启、进程退出、取消/慢读测试串行，结束清理全部临时资源。

真实调用显式--run-live；确认本方案后才在本机把用户提供的CSV凭据导入独立credentials.yaml，密钥不打印、不入快照/数据库/日志/审查材料。缺权限、配置或模型不可用不是通过/静默跳过。普通API地址和模型ID固定留证，分别记录文档能力、实际出站、上游原始结果及Gateway结果；SDK协议兼容不替代逐模型验证。

精确小数检查HTTP→JSON→Schema→SDK实际出站字节→返回解析→DB/账务，禁止自动float舍入掩盖差异。费用黄金独立手工按官方档位/缓存规则计算，不调用被测计价函数产生期望值。使用屏障/受控时钟证明分类完成不等于请求完成、供应商结束不等于客户端收到，真实取消只报告观察到的本地关闭与已确认Usage。

### 3.2 验收样例和真实矩阵

预先固定的合成标签按设计三档规则事先固定，职责/用户问题/上下文共同组成任务，所有订单/消费者信息为合成数据。开发集与验收集独立编号/摘要；验收集不进入Few-shot或Prompt调优。首次正式分类评估失败须保留，不因更贵模型或随后重跑成功改写。供应商故障单列端到端可用性，不作为分类正确；应有30个有效分类结果用于判断质量，补验保留失败与版本边界。分类错误修复需有新封存集，避免反复用同一验收集调参。

真实矩阵：三模型分别普通、结构化、真流式及健康；Flash分类并命中三组；真实同一ID两阶段用量与费用；受控分类失败＋真实Plus默认；三模型取证及取消/续传；真实校准；固定验收分类；混合容量。无法强迫真实供应商按脚本503/超时，因此故障的确定时序用Mock/回环协议制造，真实备用部分保留真实Adapter，不把回环故障写成供应商事故。
