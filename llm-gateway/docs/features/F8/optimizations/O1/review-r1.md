### 独立反例

- **显式传入空流脚本。** `stream_events=[]` 不满足 `events is None`，不会生成默认终态。迭代耗尽后网关产生 `provider_invalid_response`，没有模拟用量可计入 Attempt。静态确定。
- **主模型超时后，备用 Mock 成功。** 普通响应的整体用量仍为 `null`；诊断的已知小计为 11，未知列表只有 `[1]`。两者聚合口径不同且符合原契约。执行者的目标回执覆盖了这个组合。
- **两个请求共享默认 Mock，其中一个在流式增量后停止。** 样本只随已观察到的 Provider 终态进入流式 Attempt。另一个请求的普通成功结果不会给该流补记用量。依据为冻结值、按请求保存的 Attempt 和按 `request_id` 聚合，属于静态推导。
- **重复订阅同一终态。** 流式用例先收到 delta 和 completed，再从 delta 的序号重放同一 completed。回放后 Provider 仍只被调用一次，数据库仍只有一条 Attempt，已知小计仍是 11。
