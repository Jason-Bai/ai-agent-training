## 1. 本阶段交付

交付面向内部 Agent 的模型调用服务，部署边界为本机或隔离开发网络、单实例、单 worker，允许多个内部 Agent 并发访问。Gateway 管调用工程，Agent/Harness 管任务、工具和业务决策。

| 已验收功能 | 交付能力 |
| --- | --- |
| F1、F1-O1 | FastAPI 统一入口、响应与错误处理、应用组装和环境配置。 |
| F2 | 受控 Prompt 模板、固定 System、User 变量、Few-shot、版本和渲染指纹。 |
| F3、F3-O1 | 逻辑模型配置、统一 Provider、能力检查、Token/超时预算、主动探测与组件导读。 |
| F4、F4-O1 | 普通调用的 Structured Output、严格 JSON/Schema 验收、十进制保真及共享常量/工具。 |
| F5、F5-O1、F5-O2 | 增量 SSE、15秒空闲心跳、PostgreSQL 持久化、两阶段调用、按 seq 续传及后台生成与订阅隔离。 |
| F6 | pending/running 主动取消、清理、轮询至互斥终态；取消与上游协议无关。 |
| F7 | 有限重试、能力匹配的 fallback、截断预算增长和结构化受控修复，共享总期限与尝试上限。 |

| F10 | 独立调用方使用闭环、故障与账务核查、真实并发/持续运行、完整历史回归和独立审查。 |

## 3. Mock 与真实 Provider 的定位

两者互补，分别保留证据。

| 类型 | 用途 | 结论边界 |
| --- | --- | --- |
| MockProvider、受控协议上游 | 跑通流程、稳定复现特殊场景，例如超时、重试、畸形输出、取消竞争和未知费用。 | 证明对应输入及时序下的Gateway行为，不作为远端连通、质量或容量证明。 |
| 真实 Provider | 检验指定接入在真实环境中的协议、回答、延迟、流式行为、Usage及上游失败表现。 | 结论限定于实际Provider、环境和负载，不能替代确定性故障测试。 |

测试应显式选择各自的Provider，开发配置切换不应改变Mock测试行为。该隔离目标仍有BUG-002遗留，不能因为默认Mock配置下全量通过就宣称所有配置变体均已隔离。当前开发绑定保持原状，本次不切换Provider或读取凭据。
