# F10 实施步骤

1. 集成者建设 tests/f10_support.py，隔离数据库、真实管理 CLI、独立 Gateway 子进程、真实 HTTP 客户端及采样接口；以 TDD 验证核对逻辑能区分错误结果。
2. 两个独立任务并行编写使用闭环与容量/持续运行，分别拥有 test_f10_acceptance.py、test_f10_capacity.py 和各自辅助。共享 support、conftest、产品接线及最终证据由集成者统一修改。
3. 首先针对核验逻辑执行 Red/Green，确认用例收集与正确替身边界；真实调用、容量、宿主故障和全量串行。测试观察与现有产品契约不一致时诊断并走 Bug 路径。
4. 跑通操作手册、生成环境与容量报告，并对最终代码不筛选完整开启 --run-live 回归。固定源码/配置，交全新 Agent 独立审查，保留实际提示词、基线、差分及报告。
