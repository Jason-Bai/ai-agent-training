# F8-O1 默认 Mock 上报模拟用量

设计已确认。基线见 [F8](../../design.md)。本地配置创建的 MockProvider 默认成功时，普通响应和流式终态各上报一次确定的 Usage，让开发者可以用 request_id 核对响应、Attempt 和 Trace。

固定样本采用输入 10、输出 1、合计 11。输出 1 也适用于最小的正整数输出预算。这组值仅用于模拟 Provider 上报，与文本长度、本地输入预算及供应商账单无关。模拟来源通过 Attempt 的 adapter=mock 识别。

显式传入的普通结果、流式事件或异常具有优先权，包括自定义用量和缺失用量。增量事件不携带用量。沿用当前汇总及存储逻辑，历史请求按当时记录查询。验收见[测试方案](test-plan.md)。
